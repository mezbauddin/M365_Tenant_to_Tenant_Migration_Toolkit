# Branching

> **Owner:** Mezba Uddin · **Last meaningful update:** 2026-11-20

**TL;DR:** `main` only. Commit straight to `main` and push at once. No branches, no pull requests.

- If a session ends up on another branch, merge it back fast-forward only and delete it.
- Commit messages follow the existing pattern: `<Script or part> <version>: <what changed>`, for example `Move-TenantDevices 1.4.6: option 9 moves stand-alone PCs too`.
- No AI attribution lines in commit messages.
